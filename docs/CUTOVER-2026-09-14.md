Deletion gate: **approved for the production corpus**. OPF is active; the
inactive WAPF plugin and its WAPF-only MU patches were removed after the
checks below. Historical `_wapf_meta` order data remains because OPF converts
it when a customer uses “order again”.

  through stable choice slugs rather than a hardcoded field ID.
- Official build, graceful reload, FastCGI/Redis and Cloudflare purge ran;
  smoke tests passed after deployment.
- Guest browser cart E2E: URL, Opción 2, América Latina and Plus changed the
  50-vote row from USD 7.50 to USD 18.00; the server cart returned the same
  USD 18.00 subtotal and the selected OPF values.
- A real pre-cutover order item (46221) now restores all four fields through
  OPF on “order again”.
- Production corpus audit: 651 global plus 18 local groups; no unsupported
  field type, clone/repeatable field, or conditional rule is in use.

## Implemented in this pass

OPF price event and quantity table integration; admin/API/PRO/schema field
discovery; cart selection serialization; disabled-choice validation;

## Scope note

OPF intentionally does not implement WAPF's unused date constraints, file
uploads, repeatable clones, or linked-product behaviour. A future import
using any of those features must be reviewed before publication.

No production orders or duplicate products were created by this verification.
