Translation options


Track where strings appear on the site

WPML can keep track of where strings are used on the public pages. Activating this feature will enable the 'view in page' functionality and make translation easier.

  • String Tracking allows you to see where strings come from, so you can translate them accurately. It needs to parse the PHP source files and the output HTML. This feature is CPU-intensive and should only be used while you are developing sites. Remember to turn it off before going to production, to avoid performance problems.
